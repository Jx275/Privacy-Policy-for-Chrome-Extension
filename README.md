# Privacy-Policy-for-Chrome-Extension
Article Copier does not collect, store, or transfer any user data of any kind whatsoever. It will never do so at any point in the future, either. This extension is purely local, has no external web connectivity, and is only distributed to a select group of users with no plans for broader publication. This privacy policy is only here to comply with Chrome's minimum requirements, since you cannot distribute a local extension without publishing it on the Chrome Store.
